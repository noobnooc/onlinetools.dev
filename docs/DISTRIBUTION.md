# Distribution & Backlink Checklist — onlinetools.dev

发布渠道清单，用于获取外链（backlinks）与曝光。按「回报 / 投入」大致排序。

- **Link 列** — `dofollow` 传递 SEO 权重；`nofollow` 主要带来流量/曝光而非权重；`—` 视具体页面。
- 勾选 `[x]` 表示已提交。第一次提交时准备好一句话简介、一张 OG 截图、和一段 100 字左右描述即可复用。

**一句话简介（可直接复用）：**
> onlinetools.dev — Local-first, keyboard-first developer tools. 60+ tools (JSON, encoding, crypto, text, image, time…) that run entirely in your browser — input never leaves your machine. No login, no ads, `⌘K` to any tool.

---

## 1. 开发者工具目录 / Awesome Lists（GitHub，dofollow，性价比最高）

给 GitHub 上相关的 `awesome-*` 仓库提 PR 加一行链接，几乎都是 dofollow，长期有效。

- [ ] **awesome** (sindresorhus/awesome) — 顶级聚合，先进子列表
- [ ] **awesome-devtools** / **awesome-dev-tools** — 搜 GitHub `awesome dev tools`
- [ ] **awesome-selfhosted / awesome-privacy** — 主打「local-first、数据不出浏览器」正好契合
- [ ] **awesome-json** / **awesome-tools** / **free-for-dev** (ripienaar/free-for-dev)
- [ ] **awesome-cloudflare**（你用 CF Workers，算生态案例）
- [ ] **public-apis / awesome-static-website** 类清单（若适用）
- 做法：`site:github.com awesome developer tools` 搜出 10~20 个，逐个提 PR。

## 2. 「在线工具 / 免费工具」聚合站与目录

- [ ] **AlternativeTo** (alternativeto.net) — 列成 CyberChef / DevUtils / IT-Tools 的替代品，dofollow
- [ ] **Product Hunt** (producthunt.com) — 见第 4 节，单独发布
- [ ] **SaaSHub** (saashub.com) — 工具目录，dofollow
- [ ] **Toolsforgo / Toolfinder / Tiny Tools Directory** 等 tools 目录

## 3. 具体「同类工具」的替代品收录（精准流量）

把自己登记为这些知名工具的「在线/替代」版本：

- [ ] **IT-Tools** (it-tools.tech) 生态、**CyberChef**、**DevUtils.app**、**DevToys** 的替代品页

## 4. 产品发布平台（一次性大曝光）

- [ ] **Product Hunt** — 周二/周三 00:01 PST 发布效果最好；准备 gallery 截图 + 首条评论
- [ ] **Hacker News** (news.ycombinator.com) — `Show HN: onlinetools.dev – local-first browser tools`。隐私/local-first 卖点在 HN 很吃香
- [ ] **Lobsters** (lobste.rs) — 需邀请；`show` 标签
- [ ] **Indie Hackers** (indiehackers.com) — 发 Show/里程碑帖
- [ ] **BetaList / Peerlist / Uneed / Tinylaunch / Fazier** — 独立产品发布站，多为 dofollow
- [ ] **DevHunt** (devhunt.org) — 专为开发者工具的 Product Hunt 替代
- [ ] **Startup Fame / Side Project Stack / Launching Next** — 长尾发布目录

## 5. Reddit / 论坛社区（曝光 + 部分外链）

## 10. 每个工具页做「工具专属」外链（长尾，规模化）

60 个工具 = 60 个可被单独收录的落地页。针对高频工具（JSON formatter、Base64、UUID、JWT decoder、时间戳转换）单独去对应的 awesome-json / awesome-crypto 列表登记，长尾累积权重最稳。
